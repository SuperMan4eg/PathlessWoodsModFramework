# Changelog

## 0.1.1

- Place the Mods launcher above the QQ group numbers, leaving the native social button accessible.
- Document the BepInEx console setting and publish framework source under MIT.

## 0.1.0

- Add an in-game mods menu with plugin details and search.
- Edit supported mod settings, validate declared limits and save applied values.
- Provide mod metadata registration and queued main-thread callbacks.
- Support independently installed language packs and Cyrillic fonts.
- Improve fitting and refresh behavior for selected settings, status and item captions.
- Supply a separate SDK with API documentation and a compilable example mod.
